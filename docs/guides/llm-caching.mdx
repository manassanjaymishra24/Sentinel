# LLM Cost Control

Querying frontier LLMs for high-volume logs is economically impractical for production SOC pipelines. Sentinel prevents cost blowouts using **Token Budgeting** and **Response Caching**.

## Budget Configuration

```python
from sentinel.llm import SafetyEnvelopeReasoner

reasoner = SafetyEnvelopeReasoner(
    model="gpt-4o-mini",
    token_budget=10000,          # Hard ceiling on LLM spend
    cache_threshold=0.85         # Similarity index to reuse cached determinations
)
```

## Economic Breakdown

| **Ingestion Strategy** | **Daily Tokens (10k events)** | **Estimated Cost ($0.003/1k tokens)** |
| ---------------------------------------- | ----------------------------- | ------------------------------------- |
| **Uncached LLM Parsing** | ~5,000,000 | **$15.00 / day** |
| **Sentinel Safety Envelope (90% Cache)** | ~50,000 | **$0.15 / day** |
