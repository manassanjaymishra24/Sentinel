# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x: |

## Reporting a Vulnerability

Do **NOT** report security vulnerabilities through public GitHub issues.

1. Email your findings privately to `manassanjaymishra24@gmail.com`.
2. Encrypt sensitive payloads using our PGP key (available upon request).
3. Include:
   * Target component (`sentinel.defense`, `sentinel.response`, etc.)
   * Proof of concept or reproduction steps
   * Potential threat impact (e.g., prompt injection leading to bypass, command injection in response adapters)

## Response Commitment

* **Initial Acknowledgement:** Within 24 hours.
* **Triage & Reproduction:** Within 72 hours.
* **Patch Release & Advisory:** Within 14 business days.
