Do **not** report security vulnerabilities through public GitHub issues. Full details live in [`SECURITY.md`](https://github.com/manassanjaymishra24/Sentinel/blob/main/SECURITY.md) in the repository root.

## Quick summary

1. Email findings privately to `manassanjaymishra24@gmail.com`.
2. Include the target component (e.g. `sentinel.defense`, `sentinel.response`), reproduction steps, and potential threat impact.
3. Response commitments: acknowledgement within 24 hours, triage within 72 hours, patch/advisory within 14 business days.

For a breakdown of what Sentinel is and isn't designed to catch, see the [Threat Model](/concepts/threat-model).
